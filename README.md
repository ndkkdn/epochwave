# Back to the Future — 1955 → 2026

영화 *Back to the Future* 의 1955년을 출발점으로 삼아 2026년까지 70년의 **한국사와 세계사를 나란히** 보는 연표.

**배포 주소** — https://ndk.hello-world-history.workers.dev
**파이프라인 설계도** — [Timeline Engine Blueprint](https://claude.ai/code/artifact/53db5038-8301-4c57-977e-8c6e6545d3f4) (데이터 흐름·레이아웃·시그니처 인터랙션 도해)

---

## 파이프라인

```
content/events.json  ──validate──▶  build.mjs  ──inline──▶  dist/index.html
   (사람이 편집하는 원본)             (스키마·연대 검증)      (CSS·JS 전부 인라인)
          │                                                      │
          ▼                                                      ▼
   KV: data:events                                        KV: page:index
          └──────────────────┬───────────────────────────────────┘
                             ▼
                   Worker (src/index.js)
                GET /             → page:index
                GET /api/history  → data:events
                POST /api/chat    → Workers AI (Gemma-4)
```

페이지와 데이터를 KV 키로 분리했기 때문에 **역사 콘텐츠만 고칠 때는 Worker 재배포가 필요 없다.**

위 흐름과 시그니처 인터랙션(엣지→사각형 전개)을 도면 형태로 정리한 문서 — [Timeline Engine Blueprint](https://claude.ai/code/artifact/53db5038-8301-4c57-977e-8c6e6545d3f4).

## 명령

```bash
npm run validate   # 스키마·연대·아이콘·병행표기 검증만
```

```bash
npm run release    # 검증 + 빌드 + KV 업로드 (콘텐츠 수정 시 이것만)
```

```bash
npm run deploy     # 위 전체 + Worker 재배포 (src/index.js 를 고쳤을 때)
```

`.env` 의 Cloudflare API 토큰을 `push-kv.mjs` 가 자동으로 읽는다.

## 사건 데이터 스키마

```jsonc
{
  "id": "1960-04",          // "YYYY-MM" — year/month 와 일치해야 함
  "year": 1960, "month": 4,
  "era": "cold-war",        // eras[].id 중 하나
  "anchor": "korea",        // 이 사건을 어느 트랙(위=world / 아래=korea)에 놓을지
  "title": "4·19 혁명",
  "icon": "protest",        // index.html 스프라이트의 #i-<icon>
  "note": "…",              // 선택 — 카드 상단 앰버 각주
  "korea": { "headline": "…", "figures": ["이승만"], "body": "…" },
  "world": { "headline": "…", "figures": ["샤를 드골"], "body": "…" }
}
```

`korea` 와 `world` 는 **둘 다 필수**다. 요구사항의 "한국사·세계사 병행 표기"를 검증 단계에서 강제한다.
`body` 는 130자를 넘으면 경고가 뜬다 (카드 레이아웃이 길어짐).

## 주가 곡선

레일 위(세계=S&P 500)·아래(한국=KOSPI)에 로그 스케일로 얹었다. 헤더의 **주가** 토글로 켜고 끌 수 있고,
점에 마우스를 올리면 그 해 값과 전년 대비 변동률이 뜬다.

**클릭하면** — 급락·급등한 지점을 포함해 모든 점이 사건 카드와 똑같은 엣지→전개 팝업으로 상세를 보여준다.
값·전년 대비 변동률 아래로:

1. **경제사 각주** (`markets[].notes`) — 그 해 지수가 왜 그렇게 움직였는지에 대한 전용 해설. 일반 사건에는 없는
   순수 경제사(닉슨 쇼크, 블랙먼데이, 3저 호황 등)를 채운다.
2. **같은 해의 일반 사건** — 등록돼 있으면 목록으로 뜨고, **"이 사건 열기 →"**를 클릭하면 그 카드로 바로 넘어간다.

둘 다 없으면 "등록된 사건이 없는 해입니다"가 뜬다.
(예: S&P 500 1987 클릭 → 247, ▲2.1% → 경제사 "블랙먼데이" + 같은 해 사건 "6월 민주항쟁" 함께 표시)

```jsonc
"markets": [
  { "id": "sp500", "label": "S&P 500", "track": "world", "color": "#4DA3FF",
    "series": [[1955, 45], [1956, 47], /* … */] },
  { "id": "kospi", "label": "KOSPI", "track": "korea", "color": "#FF6B4A",
    "series": [[1980, 107], /* … */] }
]
```

- 연말 종가 기준 **근사값**이다 (인터넷 접근이 없는 빌드 파이프라인이라 실시간 조회 대신 하드코딩) — 정확한 숫자가 필요하면 실제 데이터로 교체할 것
- KOSPI는 1980년 산출 시작이라 그 이전은 곡선이 없다
- `validate.mjs` 가 연대순·양수·범위를 검사하고, 빠진 해가 있으면 경고한다 (직선으로 건너뜀)
- 기간 선택 슬라이더로 구간을 좁히면 그 구간만 밝게 남고 나머지는 흐려진다 (추세 맥락은 유지)

> **주의(수정됨)** — `#nodes` 오버레이 div가 `pointer-events`를 막고 있지 않아서, 실제 마우스 클릭으로는
> 주가 포인트를 클릭할 수 없던 시기가 있었다(`dispatchEvent`로 직접 쏘는 테스트에서는 hit-test를 우회해서 드러나지 않았다).
> `#nodes{pointer-events:none}` + `.node{pointer-events:auto}`로 고쳤다 — 빈 영역의 클릭만 아래 SVG로 통과시킨다.

## 시그니처 인터랙션

노드를 클릭하면:

| 시각 | 단계 |
|---|---|
| 0–200ms | 노드에서 **엣지가 뻗어** 카드의 앵커 모서리까지 도달 |
| 200–310ms | 엣지 끝점이 사각형의 시작점이 되어 **가로로 펼쳐짐** |
| 310–620ms | 이어서 **세로로 펼쳐짐** |
| 420–700ms | 제목 → 연월 → 세계사 → 한국사 순차 등장 |

`clip-path: inset(… round 16px)` 를 마스크로 걷어내는 방식이라 텍스트가 왜곡되지 않고, 전개 내내 라운드 모서리가 유지된다. 앵커 모서리는 노드 위치에 따라 4방향(`top-left` / `top-right` / `bottom-left` / `bottom-right`) 중 자동 선택된다.

**닫기** — 빈 곳 클릭 · `Esc` · 다른 노드 클릭. 접히는 애니메이션은 200ms로 더 빠르다.

**좁은 화면** — 카드를 노드 옆에 놓을 가로 여유가 없으면 세로 배치로 전환하고 노드를 화면 중앙에 맞춘다.

## 기간 선택

헤더 아래 듀얼 슬라이더로 1955–2026 중 원하는 구간만 볼 수 있다.

- 양 끝 손잡이를 드래그하면 그 구간 밖의 노드·줄기는 숨고, 시대 배지·연도 눈금은 흐려진다
- 뷰가 자동으로 구간 시작점까지 스크롤된다
- 열려 있던 카드가 구간 밖으로 밀려나면 자동으로 닫힌다
- **전체 보기**로 즉시 초기화
- 좌우 방향키 내비게이션은 숨겨진 노드를 건너뛴다
- 창 크기가 바뀌어 레이아웃이 다시 그려져도 선택한 구간은 유지된다 (`App.range`)
- **기간 선택 바 위에서 마우스 스크롤**하면 폭은 그대로 두고 구간 전체가 앞뒤로 밀린다 (연 단위, 양끝에서 클램프)
- **연표 본문 위에서 마우스 스크롤**하면 세로 휠이 가로 스크롤로 바뀐다 — 트랙패드 가로 스와이프·Ctrl+휠(확대)은 그대로 둔다

## AI 가이드 챗봇

우측 하단 **AI 가이드** 버튼 — Cloudflare Workers AI의 **Gemma-4**(`@cf/google/gemma-4-26b-a4b-it`)로 답한다.

- Worker가 `data:events`(사건 + 주가 데이터)를 통째로 근거 자료로 프롬프트에 넣어서, **연표 밖의 내용은 지어내지 않는다.**
- 등락률 상위/하위(예: "KOSPI가 가장 많이 오른 시기는?")는 서버에서 미리 계산해 프롬프트에 넣는다 — gemma-4-26b-a4b-it은 사고(reasoning) 모델이라, 71개 연도를 손으로 재계산하게 두면 `max_tokens`를 다 써버리고 답을 못 낸다. 그래도 가끔(사고가 길어질 때) 잘리는 경우가 있어 **한 번 자동 재시도**한다.
- 답변은 `{"reply": "...", "refs": [...]}` 형태의 JSON만 출력하도록 강제한다. `refs`는 사건 id(`"1997-11"`) 또는 주가 지점(`"mkt:kospi:1997"`) — 서버가 실제 존재하는 id인지 검증한 뒤 클라이언트로 보낸다.
- 클라이언트는 `refs`를 받아 해당 노드·주가 지점을 **펄스로 하이라이트하고 그쪽으로 스크린을 스크롤**한다. 카드는 자동으로 펼치지 않는다(챗 패널에 가려질 수 있어서) — 필요하면 사용자가 직접 클릭.

### 대화 기록 — KV에 저장

- 브라우저 `localStorage`에 세션 ID(UUID)를 하나 만들어 두고, 매 메시지마다 그 ID로 보낸다.
- Worker는 KV 키 `chat:<sessionId>` 에 `{messages:[...], updatedAt}` 형태로 대화를 쌓는다 (최근 40턴까지, 그 이상은 앞에서부터 잘림).
- 프롬프트에 넣는 맥락(최근 6턴)도 클라이언트가 아니라 **이 KV 기록에서** 읽는다 — 그래서 새로고침해도, 다른 탭에서 같은 세션 ID로 열어도 대화가 이어진다.
- 페이지를 열 때 `GET /api/chat?sessionId=...`로 기존 대화를 불러와 그대로 렌더링한다.

```bash
wrangler ai models   # 사용 가능한 모델 확인
wrangler kv key get "chat:<sessionId>" --namespace-id=16da29a4e4de45bea07749a0dbe1ef59 --remote   # 저장된 대화 확인
```

모델을 바꾸려면 `src/index.js`의 `CHAT_MODEL` 상수만 고치면 된다.
